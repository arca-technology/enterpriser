Privacidade e uso de dados

Antes de usar o CMS, confirme que você compreende como os dados são tratados:

  • Dados cadastrados ou importados, como nomes, e-mails, telefones, empresas, negociações e tarefas, são armazenados no banco Supabase do CMS.
  • Na versão web, o CMS roda no navegador e conversa diretamente com o Supabase para autenticação, cadastros, negócios, entregas e tarefas.
  • Conversas podem ser importadas manualmente por arquivos exportados. A captura automática de WhatsApp Web, Reddit Chat e Google Contatos fica reservada à extensão Chrome.
  • Os dados são usados exclusivamente para organizar o relacionamento comercial e as entregas. Não vendemos dados e não os usamos para publicidade.

Consulte a Política de Privacidade completa, que informa coleta, uso, armazenamento, compartilhamento, retenção e exclusão.
